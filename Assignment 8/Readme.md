# 📊 Marketing Campaign Performance Dashboard

## 📌 Project Overview

The **Marketing Campaign Performance Dashboard** is an interactive Power BI project developed to analyze and visualize marketing campaign performance across different campaign types, marketing channels, companies, customer segments, and locations.

The project uses a large-scale marketing campaign dataset containing **200,000 campaign records** and provides an interactive dashboard to monitor important marketing KPIs such as **Total Campaigns, Impressions, Clicks, Conversion Rate, ROI, Engagement Score, and Acquisition Cost**.

The dashboard helps users identify high-performing campaigns, compare marketing channels, analyze customer segments, and understand campaign performance trends over time.

---

## 🎯 Problem Statement

Marketing teams generate large amounts of campaign data across different channels, campaign types, companies, customer segments, and locations. Manually analyzing this data makes it difficult to identify high-performing campaigns and understand which marketing strategies generate better results.

This project develops an interactive **Marketing Campaign Performance Dashboard using Power BI** to transform campaign data into meaningful visual insights. The dashboard enables users to monitor KPIs, compare campaign performance, analyze ROI and conversion rates, and make data-driven marketing decisions.

---

## 🎯 Objectives

The main objectives of this project are:

- To analyze marketing campaign performance using Power BI.
- To monitor important marketing KPIs.
- To compare ROI across different campaign types.
- To analyze conversion rates across marketing channels.
- To identify high-performing companies.
- To analyze customer segment performance.
- To compare campaign performance across locations.
- To analyze campaign performance trends over time.
- To provide interactive filtering using Power BI slicers.
- To support data-driven marketing decision-making.

## 📂 Dataset

The project uses a **Marketing Campaign Dataset** containing **200,000 records and 16 columns**.

### Dataset Columns

| Column | Description |
|---|---|
| `Campaign_ID` | Unique identifier for each campaign |
| `Company` | Company responsible for the campaign |
| `Campaign_Type` | Type of marketing campaign |
| `Target_Audience` | Target audience of the campaign |
| `Duration` | Campaign duration |
| `Channel_Used` | Marketing channel used |
| `Conversion_Rate` | Percentage of users converted |
| `Acquisition_Cost` | Cost of acquiring customers |
| `ROI` | Return on investment |
| `Location` | Campaign location |
| `Language` | Language used for the campaign |
| `Clicks` | Number of clicks generated |
| `Impressions` | Number of impressions |
| `Engagement_Score` | Campaign engagement score |
| `Customer_Segment` | Target customer segment |
| `Date` | Campaign date |
